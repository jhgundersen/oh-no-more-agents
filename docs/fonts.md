The official `text=` request includes printable ASCII, non-breaking space,
middle dot, multiplication sign, smart quotes, ellipsis, chevron, four arrows,
minus and infinity. Other characters fall back to the system monospace font.
The file is served locally; no additional runtime third-party request or
font-building dependency is needed. The existing Orbitron font and theme
button treatment are retained. Long patch-note/footer prose uses system
monospace rather than the display face.

Treat this numbered filename as published artwork: a replacement gets a new
number and new preload/CSS URLs. Never overwrite an already-published version.
The asset currently uses the server's normal revalidation policy.
